# MAD-Project-True and Position Guess Game
App Name: True and Position Guess Game
Tagline: Think, guess, and outsmart—two players, one challenge.
Project Description: The proposed solution is the development of an Android-based two-player logic game called True & Position Guess Game. This mobile application is designed to combine entertainment with mental stimulation by engaging players in a competitive number-guessing challenge. Each player secretly selects a number, and they take turns guessing each other’s number. After every guess, the system provides instant feedback: “True” indicates correct digits regardless of position, while “Position” shows digits correctly placed. The game continues until one player successfully guesses all digits in the correct positions.
Through this structured feedback system, the app encourages players to apply logical reasoning, pattern recognition, and strategic thinking to narrow down possibilities with each turn. The user-friendly interface and real-time interaction make it accessible for students, puzzle lovers, and casual gamers who want to test and improve their analytical skills while competing with friends.
